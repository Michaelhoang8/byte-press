          How to read the numbers
          

            Entropy is measured from this file’s byte frequencies. Mean code length describes the
            Huffman payload, while container size also includes the fixed header and up to seven
            padding bits. CRC-32 detects accidental corruption; it is not authentication or
            encryption.
