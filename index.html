            The byte codebook
            

              Frequent bytes get short codes. UTF-8 characters may occupy several bytes. The codes
              are prefix-free; none begins with another complete code.

            How to read the numbers
            

              Entropy is measured from this file’s byte frequencies. Mean code length describes the
              Huffman payload, while container size also includes the fixed header and up to seven
              padding bits. CRC-32 detects accidental corruption; it is not authentication or
              encryption.
            

          

        

      

      

        HUF1 file format

        

          HUF1Length + CRC-32256 byte frequenciesPacked Huffman bits
        

        

          A fixed 1,036-byte header plus a packed payload. Small files may grow. This is a custom
          teaching format, not ZIP or gzip.
        

        

          Files stay in the browser. Decoding checks the declared size, codebook, padding,
          frequencies, and checksum before enabling a download.
